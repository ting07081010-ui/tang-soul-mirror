# 唐詩心印：長安靈魂迴響

Mobile-first literary exploration. HTML5 + Vanilla JavaScript + CSS + front-end JSON. No backend, keys, account or analytics.

## Features
- Six questions, eight preference dimensions. Original four questions retained, two added for equal exposure (every poet appears three times). Ties use the latest relevant choice, disclosed on the result.
- Eight profiles, 18 sourced poem excerpts, daily reflections and four two-branch literary micro-scenes.
- Device-local localStorage for quiz history, collection and completion, with a clear-data control.
- Canvas PNG exports: 1080×1080 and 1080×1920. Device-native sharing is user-triggered only.
- Optional original synthesized ambient tones (off by default), no bundled audio recordings.
- Responsive layout, keyboard access, reduced-motion support.

## Run and deploy
Serve this directory over HTTP, e.g. `python3 -m http.server 8080`. Deploy GitHub Pages from `main`, `/ (root)`.

## Editorial notes
This is literary self-reflection, not a validated psychological assessment or treatment. Four-axis spiritual_radar values are fictional character settings; the eight-axis result shows raw answer preferences.

Profile trajectories retain the brief's wording, including modern metaphors and disputed anecdotes, with explicit on-page caveats. Scenes are literary adaptations, not historical reenactments. 蘇東坡 is Northern Song, a style extension. Not all selected poems are from 唐詩三百首.

The supplied 「淒涼滿目欲何道」 is absent from the checked 《重至衡陽傷柳儀曹》 text. It is replaced by 「千里江蘺春，故人今不見」, with this correction disclosed. Traditional-character conversion is used; 定風波 uses common 芒鞋 (source also has 芒鞵).

Each poem in data.json has its observed source URL. Interpretations, prescriptions and dialogue are new game text. Ancient poems are quoted in excerpts only. Google Fonts is optional with native serif fallbacks. Answers remain on-device.
